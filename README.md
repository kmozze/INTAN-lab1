# Лабораторная работа № 1

Проект для выполнения лабораторной работы по интервальному анализу.
Программа находит критический радиус потери полного столбцового ранга,
строит точечную матрицу-свидетель и печатает проверки в терминал.

Готовый отчёт: [`report/lab1-report.pdf`](report/lab1-report.pdf).

Исходные материалы:

- `task_1.pdf` — копия задания в папке лабораторной;
- `../Баженов Карпова интвал.pdf` — учебное пособие;
- `../AGENTS.md` — постоянные требования к лабораторным работам.

## Работа в Visual Studio Code

1. Откройте файл `lab1.code-workspace` в Visual Studio Code.
2. Установите рекомендованные расширения из уведомления редактора.
3. Выполните задачу `Python: создать окружение и установить зависимости`.
4. Для запуска программы используйте `Python: запустить программу`.
5. Для сборки отчёта используйте `LaTeX: собрать отчёт`.

Для сборки используется установленный в системе Tectonic:
`/opt/homebrew/bin/tectonic`. При первой сборке Tectonic может загрузить
недостающие LaTeX-пакеты в собственный кэш.

Те же действия доступны из терминала:

```bash
make setup
make run
make report
```

Собранный отчёт появится в `report/build/main.pdf`. Численные результаты
выводятся в терминал командой `make run`.
