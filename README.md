# Лабораторная работа № 1

Лабораторная работа по дисциплине «Интервальный анализ».

Программа находит минимальный радиус интервальной матрицы, при котором
она содержит точечную матрицу неполного столбцового ранга, и строит
соответствующие матрицу и ненулевой вектор ядра.

## Файлы

- [`main.py`](main.py) — исходный код программы;
- [`lab1-report.pdf`](lab1-report.pdf) — отчёт по лабораторной работе.

## Запуск

Для работы программы требуются Python, NumPy и SciPy.

```bash
python3 main.py
```
